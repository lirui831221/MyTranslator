# My Translator

本地优先的翻译应用 —— 你自己的软件，基于全开源组件构建。

> GitHub 仓库保存应用源码、构建脚本、测试套件定义和模型校验清单。模型权重、
> 本机构建的运行时、应用包与安装镜像体积较大，不进入 Git；其准确版本和上游来源见
> [`models/MODELS.md`](models/MODELS.md)。将对应文件放入下方“路径约定”的位置后即可构建。

## 使用

```bash
cd ~/Dev/MyTranslator
cargo run                      # 开发模式
./target/debug/my-translator   # 直接运行
```

**文本模式**：输入 → 「翻译」或 ⌘+Enter

**语音模式**：点「🎙 开始语音翻译」→ 首次弹麦克风权限（允许）→ 说话 → 1.8 秒开始滚动复核、之后约每 1.2 秒更新，稳定前缀才提交翻译 → 主窗口左侧显示识别原文、右侧独立显示翻译结果

**双人互译模式**：切到「双人互译」，分别选择语言 A 和语言 B。例如选择中文与 English 后，中文发言会自动译成 English，English 发言会自动译成中文，无需在交谈中反复切换方向。每条字幕都会标出本句的实际语言方向；确认换人后仍会强制断句，语义缓冲不会把两个人的话合成一句。

双人模式的 A/B 菜单只显示同时具备本地识别和 Hy-MT2 翻译能力的语言。两个选项必须属于可区分的语音语言族：例如简体中文与繁体中文只有书写系统差异，不能作为一组双人语音语言。若任一所选语言不在 Qwen3-ASR 的原生范围内，最终识别会自动改用 Whisper Medium，翻译仍由 Hy-MT2 完成。模式与 A/B 语言会保存到本地，下次启动继续使用。

**系统音频模式**：点「🔊 系统音频」→ 首次允许 macOS 的屏幕与系统音频录制权限 → 直接识别视频、会议或播放器音轨。音频不经过扬声器和麦克风，能绕开房间回声与环境噪声；切换时软件会先完整停止旧输入源再安全重启。

正式构建会优先使用钥匙串中的 Apple Development 身份签名，使 macOS TCC 在后续升级时继续识别为同一个应用；只有本机不存在开发者身份时才回退到临时签名，并提示系统音频权限可能需要重新授权。可通过 `MYT_CODESIGN_IDENTITY` 明确指定签名身份。

连续讲话默认每 5 秒形成一个滚动硬边界，并保留 480ms 音频重叠；如果最新 Whisper 检查点明确显示语义未完成且 ASR 队列空闲，硬边界会动态延长到 7 秒，语义完成或队列出现积压时立即恢复 5 秒上限。跨边界重复内容会自动去除。快速模式在约 0.32/0.42 秒形成候选句尾，再录制约 120ms 后滚音频；普通句约 0.44/0.54 秒收句，Whisper 临时结果显示语义未完成时才延长到最多 0.9 秒。稳定模式在 Silero 明确确认静音时约 0.48 秒收句，模糊停顿最多等待 0.8 秒。系统音频虽然报告 READY、但启动后连续 6 秒仍只有数字零信号时，会明确提示原因并自动回退麦克风；一旦捕获到过有效信号，后续正常静音不会触发回退。

短停顿后恢复说话时，软件会比较停顿前后的音高、频谱形状、过零率和能量轮廓。换人阈值会随停顿长度分级：低于 200ms 使用 0.55，200–400ms 使用 0.42，超过 400ms 使用 0.34；两个相隔 80ms 的 160ms 特征窗口必须连续通过，确认后再执行 250ms 防抖。确认换人后会回切到停顿位置，强制结束上一位说话者并为下一位创建新的 utterance；该边界作为独立控制标记按 ASR 顺序传递，即使上一人的最终识别没有新增文字，也禁止语义缓冲把两人的内容重新合并。

识别和翻译使用两个独立的有序流水线：慢翻译不会阻塞后续识别；识别忙时，同一句尚未处理的中间检查点只保留最新版本，最终检查点始终保留，避免长时间使用后延迟不断堆积。最终识别片段会携带音频结束原因，在语义线程的同一次处理里完成边界判断并立即送入翻译线程；无文本或被质量门控过滤时仍由独立边界事件兜底。

稳定识别进入翻译前还有一层语义缓冲：完整长句和带结束标点的句子立即翻译；滚动边界出现标点、语气词、完整问句或完成名词结构时也立即翻译，弱谓词结尾才跨段保留。自然停顿后的“可能完整”句只等待 350–550ms，明显未完整句等待从 500ms 起、最多 1.4 秒；低收益历史会继续收紧上限。每批最多合并 3 片，避免上下文残缺或无限等待。

翻译任务从识别到发布始终携带独立的 `source_language / target_language`，不再从“中译英/英译中”方向反推语言。翻译使用最近 2 组同源语言、同目标语言、同模型的原文/译文作为只读上下文，改善代词、省略句、人名和连续术语；模型仍只输出当前句，切换模型、语言或会话后旧上下文会由语言对与 epoch 双重隔离。

语音翻译重新采用 Hy-MT2 前台首译：完整原文一进入翻译队列就用 Hy-MT2 快速显示右栏，不等待 Qwen3.5。每次首译和后台候选都必须通过“文字系统检查 + 本地 Whatlang 语言识别”双层目标语言门控；如果输出仍是原语言或识别成另一个目标语言，会先清空上下文严格重试，第二次仍错误则拒绝发布。短句和专有名词使用保守豁免，避免语言识别器误杀；上下文泄漏、异常长度、新增人名/数字和术语也继续受 Rust 门控。

Qwen3.5-2B MLX 4bit 作为选择性异步复核器，只在数字、否定、遗漏、术语或上下文风险命中且前台队列空闲时运行。候选必须通过目标语言、数字、术语、长度与语义一致性证据才会更新已经显示的译文；普通风格改写不会造成字幕跳动。

界面使用三档质量模式并保存选择：**极速** = Whisper Medium 最终识别 + Hy-MT2 首译 + 快断句，不启动 Qwen 翻译复核；**均衡** = Qwen3-ASR 句末最终识别 + Hy-MT2 首译 + 快断句，只复核客观风险；**高质量** = Qwen3-ASR + Hy-MT2 + 稳断句，并允许上下文类 Qwen3.5 复核。三档均保留 Whisper 流式预览和故障回退。Qwen3-ASR 与 Qwen3.5 共用 MLX 推理互斥锁，避免同时抢占 GPU。

单向模式的识别语言下拉框提供 Whisper 的完整 **100 种语言**和自动检测，其中 Qwen3-ASR 原生支持的 **30 种语言**会继续使用 Qwen 句末最终识别，其余语言自动改用 Whisper Medium，不会把不支持的语言强送给 Qwen。翻译目标下拉框提供 Hy-MT2 的全部 **38 种语言**。双人互译模式从两者的交集中选择 A/B，并对每句话做受限语言路由；所选模式、语言对、质量档位与音频来源都会保存并在下次启动时恢复。

Silero 若在强声音下连续约 384ms 异常输出零概率，系统会自动启用受限能量回退；异常持续 4 秒会重建 VAD 状态，无需手动重启语音。

ASR 结果会按音频时长、异常重复、超长无标点内容和滚动检查点漂移做质量评分。若最终结果相对完整中间结果突然缩成一两个字，会强制复核，并可恢复最近两个检查点的稳定公共前缀。Whisper 模式下，低置信度、数字密集、内容率异常或检查点不一致的非严重疑点会进入选择性高精度复核；Qwen-ASR 模式下，Qwen 是最终主结果，疑难结果仍可由 CPU Large-v3-Turbo 交叉检查。只有质量和一致性规则支持修正时才替换首版结果。

标题栏实时显示识别/翻译移动平均耗时；后台同时记录异常率、队列峰值、RMS、噪声底和 Silero 概率。最近最终结果异常率升高时，“快”模式会逐步设置 0–160ms 尾音补偿目标；候选断句已有后滚时实际追加其一半，恢复稳定后自动退回。“稳”模式不受该调节影响。

**术语表**：点「📖 术语表」编辑中英文固定译法。人名、产品名、缩写会双向匹配并在下一句生效。内置词表还包含当前宫廷剧情中反复出现的人名、ASR 音近字变体、府邸和宫廷称谓；自动翻译方向会先解析成中译英/英译中，再按实际方向应用词表。

**悬浮字幕**：点「🖼 悬浮字幕」→ 屏幕出现置顶透明字幕条
- 鼠标移入显示控制条：A+ / A- 调字号（14–64px）、✕ 隐藏
- 直接拖拽字幕可移动位置（黑描边大字，任何底色下可读）
- 与主窗口字幕同步更新，适合看视频/开会时使用

## 实测性能（M 系列 Mac）

下表是恢复后的 Hy-MT2 前台首译短句基线；选择性 Qwen3.5 复核在首版显示后异步执行，不计入首屏延迟：

| 环节 | 延迟 |
|---|---|
| whisper ASR P50 / P95 | 0.65 / 0.84 秒 |
| Hy-MT2 翻译 P50 / P95 | 0.25 / 0.31 秒 |
| 端到端 P50 / P95 | 1.33 / 1.54 秒 |

200 条 FLEURS 真实人声长句压力测试（中文/英文各 100 条）：中文 CER 8.92%，英文 WER 5.67%，端到端 P50/P95 1.62/2.27 秒。录音中位时长约 10–12 秒，超过快速模式 8 秒最大单段，因此不能直接拿这组长句延迟代表短对话；完整可复现方法见 `benchmarks/README.md`。

| 内容 | 位置 |

| whisper-cli + dylib | `bin/whisper-dist/` |

| 引擎端口 | 127.0.0.1:8341 / 8342（仅本机） |

## 换模型

- **翻译**：GGUF 放 `models/`，在 `src/main.rs` 的 translate match 加一行
- **ASR 主通道**：由三档模式绑定；极速使用 Whisper，均衡/高质量由 Qwen 接管最终识别，Whisper 继续负责实时预览与回退
- **Qwen-ASR 模型**：`models/qwen3-asr-1.7b/`，MLX 8bit
- **前台首译**：`models/Hy-MT2-1.8B-Q4_K_M.gguf`；`models/qwen3.5-2b-mlx-4bit/` 只做选择性异步复核
- **完整性检查**：运行 `./tools/verify_models.sh`；正式构建会自动拒绝缺失、篡改或外部软链接模型
