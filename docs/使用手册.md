# My Translator 使用手册

> 本地离线实时语音翻译软件 · 完全私有 · 无网络依赖
> 版本 v0.3 · 2026-10-23

---

## 软件简介

My Translator 是一款运行在 Mac 上的本地实时翻译软件：

- **完全离线**：识别（Whisper/Qwen3-ASR）、翻译（Qwen3.5/Hy-MT2/Index-2B）全部本地运行，一个字节都不出你的电脑
- **实时语音翻译**：使用麦克风或直接捕获系统音频，约 1.8 秒开始滚动识别；灰色文字为临时尾部，稳定后固定到左栏并开始翻译
- **双人互译**：选择任意受支持的语言 A/B；A 语言自动译成 B，B 语言自动译成 A，无需交谈中切换方向
- **悬浮字幕**：置顶半透明字幕条，看视频/开会时贴底显示
- **口译模式**：译文自动朗读，并按目标语言选择本机已安装的 macOS 声线
- **双向术语表**：固定人名、产品名、缩写和代码的标准译法

## 快速上手

### 第一次启动

1. 打开 `MyTranslator.app`（如遇安全提示：右键 → 打开）
2. 首次使用需授权**麦克风**（系统弹窗 → 允许）；第一次选择“系统音频”时还需允许 macOS 的屏幕与系统音频录制权限
3. 启动后自动进入语音模式，悬浮字幕条自动出现
4. 对着麦克风说话即可

### 日常使用

```
说话 → 约 0.32/0.42 秒形成候选句尾并保留约 0.22 秒尾音 → 原文+译文出现在：
  1. 主窗口左右双栏（左侧识别原文，右侧翻译结果；所有对话保留，可滚动回看）
  2. 悬浮字幕条（最新一条，置顶显示）
```

### 两个人说不同语言

1. 在控制区选择「双人互译」。
2. 分别选择语言 A 和语言 B，也可以用中间的交换按钮互换两边。
3. 开始语音翻译。说 A 语言时软件译成 B；说 B 语言时软件译成 A。
4. 查看每条字幕上方的方向标识，例如「中文 → English」或「English → 中文」。

A/B 菜单只包含同时支持本地识别和 Hy-MT2 翻译的语言。不能选择相同语言，也不能选择语音上无法可靠区分、只有书写系统不同的同一语言族（例如简体中文与繁体中文）。切换模式或语言对时，软件会重置当前 VAD、说话人画像、语义缓冲和翻译上下文，防止旧语言的内容串入新会话。

双人模式会优先使用 ASR 报告的语言，并在缺少报告时使用文本语言检测；同一个说话人回合确认语言后会锁定方向，直到确认换人或切换会话，避免滚动识别标签抖动把一句话翻成两个方向。新回合证据不足时会保守丢弃该片段。该模式适合两人轮流说话，单通道音频下无法可靠拆分两人同时重叠的发言。

## 界面功能

### 主窗口控制区

| 控件 | 功能 |
|---|---|
| **翻译模式**（单向翻译 / 双人互译） | 单向模式固定识别与目标语言；双人模式根据每句话的实际语言在 A/B 之间自动互译 |
| **语言 A / 语言 B / ⇄** | 设置双人互译的语言对；交换按钮只互换两侧，不需要重启应用 |
| **质量档位**（极速 / 均衡 / 高质量） | 一次切换识别、断句和异步复核策略；三档均由 Hy-MT2 快速首译 |
| **识别语言 / 翻译为** | 单向模式下选择输入与目标语言；识别可用 Whisper 的全部语言，翻译目标为 Hy-MT2 支持的语言 |
| **🎙 麦克风 / 🔊 系统音频** | 麦克风适合面对面说话；系统音频直接读取视频、会议和播放器声音，绕开扬声器回声与环境噪声 |
| **🎙 语音翻译** | 开关语音识别 |
| **🖼 悬浮字幕** | 开关置顶字幕条 |
| **🔊 朗读** | 口译模式：译文自动读出声 |
| **📖 术语表** | 编辑中英文固定译法，保存后下一句生效 |

语音检测带有自动恢复机制：遇到“仍有明显说话声但字幕停止”的异常时，会先启用受限能量检测，并在异常持续数秒后重建语音检测器，通常不需要手动停止再开始。

识别和翻译在后台独立运行，所以翻译较慢时左侧识别仍会继续更新。若连续讲话导致识别检查点短暂积压，软件会自动跳过同一句的过期中间版本，但一定保留最终结果。

很短、没有结束标点的识别片段会先显示在左栏，再短暂等待后续内容；软件会把属于同一意思的片段合成一行后翻译。完整句不会等待，短句基础等待约 0.9 秒，持续讲话中的片段基础等待约 1.6 秒；只有检测到当前仍在说话时才最多延长 2 次，任何一批都不会超过 3.6 秒。

短停顿后若检测到说话人的音高和频谱轮廓明显变化，软件会把停顿位置作为强制边界：上一人的内容立即独立收句，下一人使用新的语句编号，语义缓冲不会跨说话人合并。标题栏质量指标的悬浮提示会显示本次运行已确认的换人断句次数。

在双人互译模式中，这条换人边界同时也是语言路由边界：上一人的尾句先独立翻译，新说话人的文本再按 A/B 语言对确定目标。即使两句很短，也不会跨不同说话人合并。

翻译会参考最近 2 组同源语言、同目标语言、同模型的原文和译文，用来补全代词、省略句、人名与连续术语，但只输出当前句。切换目标语言、模型、识别语言或停止会话后，旧上下文不会串入新会话；固定法语、日语等目标也能正常使用上下文。

三档语音模式都先用 Hy-MT2 生成右栏首译。每个结果都经过文字系统和本地语言识别双层目标语言门控：输出仍是原语言或变成其他语言时会无上下文重试，连续两次不合格则不发布。检测到长度膨胀、前文复制、新增人名或数字时也会自动去掉历史重译；术语未遵守时使用受保护占位符重试。

- **极速**：Whisper Medium 最终识别、快断句、Hy-MT2 首译，不运行 Qwen3.5 翻译复核，延迟和内存最低。
- **均衡**：Qwen3-ASR-1.7B 8bit 最终识别、快断句、Hy-MT2 首译；只在数字、否定、遗漏和术语等客观风险出现时异步调用 Qwen3.5。
- **高质量**：Qwen3-ASR 最终识别、稳断句、Hy-MT2 首译；在客观风险之外也允许上下文风险复核，适合连续剧情和会议。

Qwen3.5 候选只有通过目标语言、数字、术语、长度和语义一致性门控才会更新首译。Whisper 始终保留滚动预览和 Qwen-ASR 失败回退；两个 Qwen MLX 任务串行推理，不会同时抢 GPU。

双人互译所选的两种语言只要有一种不在 Qwen3-ASR 原生支持范围内，句末最终识别就自动回退到 Whisper Medium；这不会缩减可选语言，也不会改变 Hy-MT2 的翻译目标。

最终识别如果从较完整的滚动结果突然缩成一两个字，会触发退化门控；软件先用更强的识别策略复核，必要时恢复最近两个检查点的稳定公共前缀。Whisper 模式的普通疑难句先发布 Medium 结果，再在前台队列连续空闲时选择性复核；Qwen-ASR 模式则由 Qwen3-ASR 直接生成句末最终结果，异常时回退 Whisper，并可用 CPU Large-v3-Turbo 交叉检查。候选必须通过质量、长度、数字和一致性门控才会替换原文并重译。

标题栏会显示近期“识别/翻译”平均耗时。将鼠标停在指标上可查看最近异常率、自动尾音补偿和队列峰值；软件只对“快”模式设置 0–160ms 的补偿目标，候选断句已有后滚时实际追加其一半，状态恢复后会自动降低。

### 术语表

- 每行填写一个中文词和对应英文，系统自动双向使用。
- 可暂时取消勾选，不必删除条目。
- 命中时先要求模型严格使用指定译法；若模型未遵守，会自动用受保护占位符重试。
- 内置示例包括 `栗战书 → Li Zhanshu`、`飞牛 → fnOS`、`Sub2API → Sub2API`，可自由修改。

### 历史记录面板

- 每句对话占一行：**左栏=识别原文，右栏=翻译结果**；两边独立更新但保持逐句对齐
- 识别完成后左栏立即显示，右栏先显示“翻译中…”；译文返回后只更新同一行的右栏
- 窄窗口会自动改为上下排列，并标明“识别原文 / 翻译结果”
- 最新在最上，最多保留 200 条
- **字号调节**：面板顶部「原文 −＋」「译文 −＋」按钮（设置自动记忆）
- **清空**：右上角清空按钮
- **自动存档**：全部对话自动写入 `~/Documents/MyTranslator-transcripts/日期.md`

### 悬浮字幕条

- 鼠标悬停显示控制：**A+ / A−**（字号 14-64px）、**✕**（关闭）
- 整条可拖动到任意位置（比如屏幕底部）
- 深色毛玻璃胶囊样式，任何背景都清晰

## 性能与资源

| 指标 | 数值 |
|---|---|
| 说话中原文预览 | 约 0.75 秒（首次切片 0.55s + base ASR 约 0.2s） |
| 停顿→首版译文 | Hy-MT2 基线 P50 约 1.33 秒、P95 约 1.54 秒；后台复核不阻塞首版 |
| 内存 | 极速最低；均衡增加 Qwen-ASR；高质量还会预热 Qwen3.5 复核器，实际值随 macOS Metal 统一内存回收变化 |
| Qwen3.5 翻译复核 | 均衡/高质量按风险异步运行，空闲 10 分钟自动释放；失败时保留 Hy-MT2 首译 |
| Qwen-ASR 最终识别 | 可选；模型常驻，Whisper 保留滚动预览和故障回退；两个 MLX 模型串行推理 |
| 磁盘占用 | App 约 6 GB（含全部离线模型与独立 MLX 运行时） |
| 完整冷启动预热 | Hy-MT2 与所选识别器后台预热；高质量档同时预热 Qwen3.5 复核器 |

## 系统要求

- **macOS 13+**，Apple Silicon（arm64）
- 最低 8GB 内存；均衡建议 16GB，高质量建议 16GB 以上
- 当前发布包不支持 Intel Mac

## 常见问题

**Q：识别把中文听成日语？**
识别语言切到「中」（默认已是）。

**Q：两个人分别说不同语言，为什么不用手动切方向？**
切到「双人互译」并选择语言 A/B。软件会按每句话的识别语言自动决定 A→B 或 B→A，并在字幕上显示实际方向。请尽量轮流说话；两人同时重叠发言无法在单通道音频中可靠分离。

**Q：没说话却一直翻译？**
环境噪声所致。软件使用 Silero v6.2 神经 VAD、连续3帧判定、自适应能量回退、波形门控和 ASR 异常质量门控；超长、重复、前后漂移或最终结果突然短缩都会自动二次识别，两次仍异常才丢弃。若翻译的是视频或会议，优先改用“系统音频”。

**Q：系统音频没有声音？**
在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许 My Translator，然后停止并重新开始语音翻译。该模式只捕获 Mac 正在播放的音频，不会采集你的麦克风；需要同时听你讲话时请切回“麦克风”。

**Q：朗读时识别自己读的内容？**
不会。朗读期间麦克风自动静音（防自激）。

**Q：历史记录重启后没了？**
界面列表是内存态，但所有对话已自动存在 `~/Documents/MyTranslator-transcripts/` 按日期归档。

**Q：怎么迁移到别的 Mac？**
复制整个 `MyTranslator.app`（或用 `MyTranslator.dmg` 重新安装），模型全部内置。
